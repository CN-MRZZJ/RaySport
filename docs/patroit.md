## 概述

Patroit 是锐赛体育智慧平台的赛事录入端，负责赛事信息的前端采集与录入。为赛事工作人员提供高效、直观的数据录入界面，支持多种赛事类型的数据采集、校验与提交。

## 核心能力

- **多赛事类型支持** — 灵活适配田径、球类、游泳等多种体育赛事的数据录入需求
- **高效录入体验** — 精心设计的录入界面与交互流程，降低操作门槛
- **数据校验** — 内置数据校验规则，确保录入数据的准确性与完整性
- **实时反馈** — 录入过程实时提示，帮助操作人员快速发现并修正问题

## 技术栈

::: info 技术栈
前端框架 · 响应式设计 · RESTful API 集成 · 表单校验引擎
:::
