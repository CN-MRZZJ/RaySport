## 概述

Verlion 是锐赛体育智慧平台的核心后端服务，承载平台全部业务逻辑处理、数据持久化、API 接口服务及第三方系统集成。作为平台的中枢，Verlion 连接录入端 Patroit 与管理端 Dervany，确保数据流转的高效与可靠。

## 核心能力

- **业务逻辑引擎** — 处理赛事全生命周期中的复杂业务规则与状态流转
- **高性能 API** — 为前后端各端提供稳定、高效的 RESTful API 接口
- **数据持久化** — 可靠的数据存储方案，保障赛事数据安全与一致
- **系统集成** — 支持与第三方计时计分系统、身份认证系统等对接
