## 概述

Dervany 是锐赛体育智慧平台的管理运营后台，面向赛事组织方与管理员，提供赛事管理、数据看板、用户权限控制等全方位的运营工具。通过直观的可视化界面，帮助管理者高效掌控赛事全局。

## 核心能力

- **数据看板** — 多维度赛事数据可视化，实时掌握赛事运营状况
- **赛事管理** — 赛事创建、编排、调度与状态跟踪的全流程管理
- **用户权限** — 细粒度的角色权限控制，保障系统操作安全
- **运营工具** — 成绩发布、通知推送、报表导出等运营辅助功能

## 技术栈

::: info 技术栈
管理后台框架 · 数据可视化 · 权限系统 · 报表引擎
:::
